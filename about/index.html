ABOUT QUOTELY

A simple place for thoughts worth keeping.

QUOTELY is a quote discovery experience built around finding, keeping and sharing ideas without turning the experience into another endless content feed.

WHAT IS QUOTELY?

QUOTELY is a lightweight quote discovery application. You can explore thoughts by category, discover a new quote, return to recently generated thoughts and save the ones you want to keep.

WHAT CAN I DO WITH IT?

Quotes can be saved permanently, copied as text or turned into a purpose-built QUOTELY image for sharing. Recent Thoughts remain available temporarily so you can return to something you discovered without automatically filling your permanent collection.

HOW DOES IT WORK?

The interface is built with HTML, CSS and vanilla JavaScript. A Cloudflare Worker acts as the trusted backend, while Cloudflare D1 stores the quote catalogue, visitor identities and Saved Thoughts.

Quote sources can be collected into D1 first, allowing QUOTELY to serve quotes from its own catalogue instead of depending on an external API every time someone presses New Quote.

WHY DOES QUOTELY USE VISITOR IDS?

QUOTELY avoids a conventional signup form. A visitor receives a recoverable six-digit Visitor ID instead. This allows Saved Thoughts to belong to the visitor while keeping the experience lighter than a normal account system.

IS QUOTELY OPEN SOURCE?

Yes. The project is open source so its interface, backend structure and implementation can be explored, studied and extended.

FROM THE CREATOR

Abbas Bhojani

Creator of QUOTELY

“A quote generator could have been a few lines of JavaScript. I deliberately made QUOTELY more complex because the simple idea gave me room to experiment with things I wanted to understand better.”

That included anonymous identity, recovery, persistent storage, server-side security, API architecture, temporary local state, share-image generation and Cloudflare's serverless tools.

The goal was never to make quotes complicated. It was to use a small product as a practical place to explore how larger product systems are designed.
